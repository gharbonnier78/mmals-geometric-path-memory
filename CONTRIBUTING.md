# Contributing

1. Keep established theory, source-manuscript claims, and new engineering hypotheses clearly separated.
2. Add a test for every numerical geometry change.
3. Avoid presenting a machine-learning analogy as a physical equivalence.
4. Record dataset versions, seeds, and curriculum order for every MMALS experiment.
5. Keep the HTML tools standalone and offline-capable.
6. Compile and visually inspect the PDF before merging documentation changes.
